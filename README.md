# Java Design Patterns: Shopping App

A desktop shopping application built with Java Swing to practice applying object-oriented design patterns in a working program.

## Design patterns

| Pattern | Where | Purpose |
|---|---|---|
| MVC | `model/`, `view/`, `controller/` | Separates data, Swing screens and application logic |
| Builder | `Builder/CustomerDataBuilder.java` | Constructs customer data step by step |
| Factory | `factory/ProductFactory.java` | Centralizes product creation |
| Strategy | `strategy/PricingStrategy.java` | Swaps between regular and discount pricing |

## Getting started

You'll need a JDK. Open the project in IntelliJ IDEA and run `ShoppingApplication`.
